# AngoTinder 💛❤️🖤

> **O Amor à Angolana.** 🇦🇴

O **AngoTinder** é a primeira plataforma de encontros (dating app) desenhada especificamente para conectar solteiros angolanos. Seja em Luanda, Huambo, Benguela ou na diáspora, o nosso objetivo é facilitar conexões reais, seguras e com a nossa identidade.


## 📱 Sobre o Projeto

Muitas aplicações de encontros globais não entendem a nossa cultura, os nossos hábitos ou as nossas necessidades de conectividade. O **AngoTinder** nasce para preencher essa lacuna.

Criámos um espaço onde podes:
- Encontrar pessoas perto de ti (por província/município).
- Conversar num ambiente seguro e verificado.
- Participar em eventos sociais exclusivos para a comunidade.

---

## ✨ Funcionalidades Principais

- **🔥 Swipe Matching:** Gosta ou passa, tal como estás habituado.
- **📍 Geolocalização Local:** Filtros por províncias (Luanda, Cabinda, Namibe, etc.).
- **💬 Chat em Tempo Real:** Mensagens instantâneas com suporte a emojis e áudio.
- **✅ Perfil Verificado:** Sistema de segurança para evitar perfis falsos (Fake Profiles).
- **🌙 Modo Escuro:** Para economizar dados e bateria.
- **🇦🇴 Cultura Angolana:** Sugestões de encontros baseadas em locais populares (Cinemas, Restaurantes, Praias).
